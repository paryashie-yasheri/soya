# Music Bands and Grammy API specification

Это статический проект со спецификацией REST API в формате OpenAPI 3.0.3 и страницей Swagger UI. Здесь нет реализации веб-сервисов, Spring Boot-проекта, контроллеров, серверного кода, Gradle/Kotlin-конфигурации или базы данных.

## Состав проекта

```text
.
├── index.html
├── openapi.yaml
└── README.md
```

## Описание

Спецификация описывает два веб-сервиса:

- `music bands` - сервис управления коллекцией объектов `MusicBand`;
- `grammy` - второй сервис под базовым путем `/grammy`.

Второй сервис для операций с группой обращается к API первого сервиса, проверяет существование группы и затем выполняет свое действие. Для операции добавления сингла класс сингла в задании не определен, поэтому в спецификации используется только название сингла через query-параметр `single-name`.

## Локальный запуск документации

Запустите обычный HTTP-сервер из каталога проекта:

```bash
python3 -m http.server 8080
```

После запуска Swagger UI будет доступен по адресу:

```text
http://localhost:8080
```

Файл `index.html` не нужно открывать напрямую через `file://`, потому что Swagger UI загружает `openapi.yaml` отдельным HTTP-запросом. Браузер может заблокировать такой локальный запрос из-за правил безопасности для файловой системы. Через HTTP-сервер `index.html` и `openapi.yaml` отдаются из одного источника, поэтому спецификация корректно загружается.

## Проверка

Проверить синтаксис YAML можно командой:

```bash
python3 -c "import yaml; yaml.safe_load(open('openapi.yaml', encoding='utf-8')); print('YAML OK')"
```

Если установлен OpenAPI-валидатор, можно дополнительно выполнить одну из команд:

```bash
npx @redocly/cli lint openapi.yaml
```

или:

```bash
swagger-cli validate openapi.yaml
```

Также можно проверить доступность спецификации по HTTP после запуска локального сервера:

```bash
curl -I http://localhost:8080/openapi.yaml
```

## Размещение на Helios

Скопируйте три статических файла на Helios через `scp`, подставив свой логин, адрес сервера и целевой каталог:

```bash
scp index.html openapi.yaml README.md <login>@<helios-host>:<target-directory>/
```

Затем разместите их в каталоге статических файлов, который отдается веб-сервером, например в `public_html`, если такая схема используется в вашей конфигурации:

```bash
scp index.html openapi.yaml README.md <login>@<helios-host>:~/public_html/<project-directory>/
```

Конкретный путь на сервере и публичный URL зависят от конфигурации Helios и учетной записи пользователя, поэтому в проекте не указывается выдуманный логин, домен или пользовательский путь.
